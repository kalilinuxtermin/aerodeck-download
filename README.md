## Descărcare

Deschide **[Releases](../../releases/latest)** și descarcă:

- **Windows:** `AeroDeck-Setup-<versiune>.exe` (instalare) sau `AeroDeck-Portabil-<versiune>.exe` (fără instalare)

La prima pornire Windows poate arăta „Windows protected your PC”: apasă **More info** → **Run anyway**.

Versiunea pentru Mac (cip Apple) urmează.
